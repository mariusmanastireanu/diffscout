Signed in as

Signing out removes the token from this browser. To revoke it on GitHub as well, open DiffScout in your GitHub settings.

Use a personal access token instead

For accounts where signing in isn't possible. Use a fine-grained token with read-only Contents and Pull requests access, or a classic token with the repo scope. Stored only in this browser.
